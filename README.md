# 📊 Diwali Sales Data Analysis (Exploratory Data Analysis)

## 📌 Project Overview
This project performs an **Exploratory Data Analysis (EDA)** on Diwali sales data using **Python** in a Jupyter Notebook environment. The primary objective is to analyze customer buying patterns, demographics, and sales trends to derive actionable business insights for improving customer experience and boosting future Diwali sales revenue.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `seaborn`, `matplotlib`

---

## 🔍 Key Data Preprocessing Steps
* **Data Cleaning:** Handled missing values (e.g., removing null entries in the `Amount` column) and dropped irrelevant/unprocessed columns (`Status`, `unnamed1`).
* **Data Type Conversions:** Converted float metrics to integer types for seamless metric aggregation.
* **Feature Engineering & Renaming:** Renamed columns for better clarity and created structured age-group/gender subsets.

---

## 📈 Key Insights & Visualizations

1. **Gender Analysis:**
   * Female buyers generated significantly higher total order counts and spending amounts compared to male buyers during the Diwali festival period.

2. **Age Group Distribution:**
   * The majority of orders and highest overall purchasing power came from the **26–35 age group**, followed by the 36–45 group.

3. **State-Wise Breakdown:**
   * States like **Uttar Pradesh, Maharashtra, and Karnataka** emerged as top contributors in both overall order count and sales revenue.

4. **Occupation & Category Highlights:**
   * Top buyers belonged to sectors like **IT, Healthcare, and Aviation**.
   * Most popular product categories included **Food, Clothing & Apparel, and Electronics & Gadgets**.
